# 浮動文字 Overlay（Android Studio 專案）

功能：
- 多行文字，每行獨立浮動、拖曳
- 點擊單行直接開啟編輯對話框（可呼叫輸入法）
- 直播鎖定：鎖定時點擊不會進入編輯
- 透明背景、橘黃漸層文字、黑色陰影
- 可調整整體字體大小及文字顏色
- Android 8.0（API 26）以上

## 編譯
使用 Android Studio 開啟專案，安裝 Android SDK 35，等待 Gradle Sync 完成，再選 Build > Build APK(s)。

第一次使用需在系統設定中允許「顯示在其他應用程式上層」。Android 13 以上可能還需要允許通知，以便顯示前景服務通知。

## 注意
這是第一個可供編譯測試的原始碼版本，尚未在實機完成相容性與長時間直播測試。不同廠牌對背景服務、浮窗和輸入法的管理可能不同。
